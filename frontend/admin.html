Overview

Invite a client or tester

How it works: Enter a username and choose an optional subscription. The system generates a one-use activation link (24 hours). After activation, issue a reusable personal sign-in link (90 days) if desired. Anyone possessing an active link can enter that client's account. Use Reset password if they forget it. Public signup is open for free memberships.

If you are administering from localhost, paste your ngrok HTTPS forwarding URL above so copied invitations contain the correct remote login link. Otherwise, the current website address is used.

For a shared public trial, use username PUBLIC TRIAL, choose your own strong password and set the exact expiry date/time. Other clients retain the normal temporary-password and activation-link flow. Date/time uses your computer's timezone (EAT in Uganda).
